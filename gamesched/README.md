# ゲーム情報スケジュール

モンスト／スマグロ／ジージェネ／プロスピの「公式の生放送・動画・イベント」の予定を
1か所でまとめて確認するための個人用スケジュールツール。

公開URL: `https://bo0639.github.io/gamesched/`

## できること

- **ホーム**: 開催中・今日・今週の予定、24時間以内のアラート、アプリ別の次の予定、公式リンク集
- **カレンダー**: 月表示（アプリ色のドット）＋日付タップでその日の予定
- **一覧**: 検索・アプリ・種別・期間（これから／過去／すべて）で絞り込み
- **情報**: 自動収集した公式サイトのお知らせと公式YouTubeの配信予定（ワンタップで予定に追加）
- 予定の追加・編集・削除、繰り返し（毎週／隔週／毎月）、確認済みチェック
- ICS書き出し（Google／Appleカレンダーに取り込み）、Googleカレンダー追加リンク
- ブラウザ通知（ページを開いている間、各予定の「何分前」設定で通知）
- GitHub同期（Personal Access Token 設定で `gamesched/data.json` に保存 → 端末間で共有）

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体（単一ファイル） |
| `data.json` | 登録済みの予定。GitHub同期を設定するとアプリから更新される |
| `sources.json` | アプリ定義（名前・色・公式リンク）と自動収集の設定 |
| `feed.json` | 自動収集の結果。GitHub Actions が更新する（手で編集しない） |
| `../scripts/update_game_schedule.py` | 収集スクリプト（標準ライブラリのみ） |
| `../.github/workflows/update_game_schedule.yml` | 毎日 07:00 / 19:00（JST）に実行 |

## 自動収集について

`sources.json` の各アプリについて、公式サイトのニュース一覧（RSSがあればRSS、無ければ
「日付＋見出し」を総当たりで抽出）と、公式YouTubeチャンネルの最新動画・配信予定を集めます。

取得に失敗したソースは `feed.json` の `status` に理由が残り、アプリの「情報」タブと
設定画面に赤い印で表示されます。URLやチャンネルIDが変わったときは `sources.json` を直せば
そのまま次回の実行から反映されます（`youtube.channel_id` が空の場合は `handles` から自動解決を試みます）。

手動で実行する場合は GitHub の Actions から「ゲーム公式情報の自動収集」を Run workflow、
ローカルなら `python scripts/update_game_schedule.py`。

## 注意

- 収集結果と初期登録の予定には、公式未確認（まとめサイト由来）のものが含まれます。
  各予定の「確度」バッジ（確定／要確認／定例（推定））と出典URLで確認してください。
- 日時は端末のローカル時刻（日本時間）として扱います。
