# ゲーム情報スケジュール

モンスト／スマグロ／ジージェネ／プロスピの「公式の生放送・動画・イベント」の予定を
1か所でまとめて確認するための個人用スケジュールツール。

公開URL: `https://bo0639.github.io/hijiri.github.io/gamesched/`
（リポジトリ名が `hijiri.github.io` でオーナーが `bo0639` のため、
ユーザーページではなくプロジェクトページとして配信される）

## ページ構成

| ページ | URL | 用途 |
| --- | --- | --- |
| 予定管理 | `/gamesched/` | 全種別の予定を登録・編集・カレンダー表示 |
| 番組・配信 | `/gamesched/live/` | 公式生放送・特番・情報番組だけを見る（閲覧専用） |

番組ページは予定管理ツールと同じ `data.json` / `feed.json` を読み、
種別が「生放送・動画・生配信イベント」の予定と、公式YouTubeの配信予約を並べる。
端末に保存した予定（localStorage）も合わせて表示する。

- 「リスト」と「カレンダー」を切り替えられる（選択は端末に保存される）
- カレンダーは各日にアプリアイコンと開始時刻、その下に概要つきの日別アジェンダ
- 詳細は画面中央に開き、そこから「この回を休止」「番組ごと削除」ができる
  （自動取得した配信予約は「この配信を非表示」。削除・休止はGitHub同期にも反映される）

## できること

- **ホーム**: 開催中・今日（開始済みも当日中は残す）・今週の予定、24時間以内のアラート、アプリ別の次の予定、公式リンク集
- **カレンダー**: 月表示（アプリ色のドット）＋日付タップでその日の予定
- **一覧**: 検索・アプリ・種別・期間（これから／過去／すべて）で絞り込み
- **情報**: 自動収集した公式サイトのお知らせと公式YouTubeの配信予定（ワンタップで予定に追加）
- 予定の追加・編集・削除、繰り返し（毎週／隔週／毎月）、確認済みチェック
- 繰り返しの「この回を休止」（番組の休止週など）。休止した回は編集画面から戻せる
- アプリはアイコン付きで表示（`sources.json` の `icon` で切り替え）
- ICS書き出し（Google／Appleカレンダーに取り込み）、Googleカレンダー追加リンク
- ブラウザ通知（ページを開いている間、各予定の「何分前」設定で通知）
- GitHub同期（Personal Access Token 設定で `gamesched/data.json` に保存 → 端末間で共有）

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体（単一ファイル） |
| `data.json` | 登録済みの予定。GitHub同期を設定するとアプリから更新される |
| `live/index.html` | 番組・配信スケジュール（閲覧専用ページ） |
| `sources.json` | アプリ定義（名前・色・公式リンク）と自動収集の設定 |
| `feed.json` | 自動収集の結果。GitHub Actions が更新する（手で編集しない） |
| `../scripts/update_game_schedule.py` | 収集スクリプト（標準ライブラリのみ） |
| `../.github/workflows/update_game_schedule.yml` | 月・水・金・土の19:00（JST）に実行 |

## 自動収集について

`sources.json` の各アプリについて、公式サイトのニュース一覧（RSSがあればRSS、無ければ
「日付＋見出し」を総当たりで抽出）と、公式YouTubeチャンネルの最新動画・配信予定を集めます。

取得に失敗したソースは `feed.json` の `status` に理由が残り、アプリの「情報」タブと
設定画面に赤い印で表示されます。URLやチャンネルIDが変わったときは `sources.json` を直せば、
main への push をきっかけにその場で収集し直します。

`sources.json` の書き方:

- `news[].urls` — 上から順に試し、最初に見出しが取れたURLを採用する（サイト改装でパスが変わっても拾える）
- `news[].match` — 正規表現に一致する見出しだけ残す（ドラクエ公式ニュースからスマグロ分だけ拾う、など）
- `youtube.channel_id` — 空なら `handles` から解決する。`@ハンドル` のほか、チャンネルURLや
  公式動画のURLでも可（動画ページからそのチャンネルIDを取り出す）
- `youtube.match` — 共用チャンネル（パワプロ・プロスピ公式、ガンダムチャンネルなど）から
  そのアプリの動画だけを残す正規表現
- `guides[]` — GameWith / Game8 などの攻略まとめ（二次情報）。記事本文の表やリストから
  「日付＋見出し」を拾う。`programs_only: true` で生放送・番組の行だけに絞る。
  収集結果は `kind: "guide"` となり、番組ページでは「二次情報」バッジが付く

手動で実行する場合は GitHub の Actions から「ゲーム公式情報の自動収集」を Run workflow、
ローカルなら `python scripts/update_game_schedule.py`。

## 更新の反映

`data.json` / `feed.json` / `sources.json` はキャッシュを使わずに取得する
（`cache: 'no-store'` とクエリ付き）ため、取得さえ走れば常に最新が表示される。
取得が走るのは次の3つ。

- ページを開いたとき
- 別のアプリ・タブから戻ってきたとき（画面復帰）
- 開いたまま放置しているとき（30分ごと）

ページ自体（HTML）はGitHub Pagesのキャッシュに乗るため、アプリの作り変えを
すぐ反映したいときは再読み込みする。

## 注意

- 収集結果と初期登録の予定には、公式未確認（まとめサイト由来）のものが含まれます。
  各予定の「確度」バッジ（確定／要確認／定例（推定））と出典URLで確認してください。
- 日時は端末のローカル時刻（日本時間）として扱います。
