設定手順
① GitHub Fine-grained Tokens でトークンを作成
② リポジトリ bo0639/hijiri.github.io を選択
③ Permissions → Contents: Read and write を付与して生成
④ 生成されたトークンを下に貼り付けて「保存・今すぐ同期」
⑤ PCとスマホの両方で設定すると、開くたびに自動で同期されます
